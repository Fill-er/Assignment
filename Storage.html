STORAGE


Storage refers to holding information somewhere. R.A.M. or Random Access Memory, is the short term for memory. It is volatile memory because the memory is automatically "erased" when the power is turned off or interupted. The R.A.M. memory is located inside the computer case on the motherboard. A motherboard is not the keyboard. The keyboard is what you type with. A motherboard holds R.A.M. memory, electronic circuits and other computer parts including the Central Processing Unit. R.O.M or Read only memory, is not volatile menaing the memory is still there when power is interrupted or turned off. When the computer is turned back on again, R.O.M memory is still in storage on the internal hard disk.
